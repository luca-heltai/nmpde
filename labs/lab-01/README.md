# Laboratory 1: From a C++ Source File to a Visualized Data Set

This laboratory is a first tour of the tools used throughout the course. We
will synchronize the course material with Git, edit and build a small C++
program in VS Code, and inspect its output in ParaView.

The example does **not** use deal.II yet. The purpose is to make the basic
edit--configure--build--run--visualize cycle familiar before introducing a
scientific library.

The source code in this directory is the reference solution for the activity.
The accompanying lesson in the course book contains the explanations and the
student exercises.
